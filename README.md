# Mining the Design Space of Multi-Agent Workflows

[Paper and interactive examples](https://junyan.ch/apex-paper/) · [arXiv paper](https://arxiv.org/abs/2610.31709) · [Workflow database](https://junyan.ch/apex-paper/explorer/) · [Research code](https://github.com/xcadet/apex)

This repository serves the paper website and the full 28,568-workflow database.
The static site lives at the root; the database build lives in explorer/.
Its React source and Apache 2.0 license are in viewer-source/.

GitHub Pages publishes the root of the default branch. The project inherits
the junyan.ch domain from the account's main Pages site. Do not add a CNAME.

The downloadable preprint and arXiv source package are in assets/.
Paper links point to [arXiv:2610.31709](https://arxiv.org/abs/2610.31709),
and the website includes its official BibTeX citation.
